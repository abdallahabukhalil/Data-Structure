# Core Data Structures in Python

## About This Repository
Building core data structures from scratch: A practical collection of fundamental data structures I studied during my Computer Science and Statistics degree, now implemented in Python.

Understanding how data is stored, organized, and accessed is crucial for building efficient systems and data pipelines. Instead of relying only on built-in libraries, I created this space to document my academic journey and implement these core structures myself. This repository serves as a practical, searchable index focusing on memory management, performance complexity, and clean Python code.

## Data Structures Index
Here is a detailed list of the data structures included. Click on any file name to view the Python code directly.

* **Linear Data Structures**
  * [`Stack.py`](./Data%20Structure/Linear/Stack.py): Implements a Last-In-First-Out (LIFO) data structure. Useful for reversing items, managing function calls, and building undo features.
  * [`Queue.py`](./Data%20Structure/Linear/Queue.py): Implements a First-In-First-Out (FIFO) data structure. Ideal for task scheduling, buffering, and managing sequential processes.

* **Trees & Graphs**
  * [`Binary Search Tree.py`](./Data%20Structure/Graph/Binary_Search_Tree.py): A node-based binary tree data structure allowing for fast lookup, addition, and removal of items. Essential for efficient searching and sorting operations.
